May 2025
>> Refactored manager registration flow:
   - When a user is registered with the "Manager" role, a merchant entry is now automatically created (if not provided) and linked to the user via the merchID field.
   - Nested merchantSerializer is now used in merchantUserSerializer for DRY and maintainable code.
   - Only managers are linked to merchants; other roles are not.
   - merchantManagerView now delegates merchant creation to the serializer, reducing redundancy.
   - Gift card creation now always uses request.user.merchID for the merchant, and only managers can create gift cards.
   - Frontend should send merchant_data only when registering a manager.
   - Improved security: managers can only create gift cards for their own merchant.
   - Database migrations applied to reflect model changes.
>> Documented the new registration and gift card creation flows for clarity and onboarding.
